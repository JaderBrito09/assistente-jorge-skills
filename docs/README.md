# 📚 Documentação do Sub-projeto Skills (`skill_extensao`)

Este diretório contém a documentação técnica, estrutura e especificações sobre a criação, manutenção e integração das **Skills** do **Assistente do Jorge**, além de fontes teóricas para alentar a **Meta-Skill Arquiteta** no NotebookLM.

---

## 📁 Estrutura da Documentação

### 📋 Guias do Projeto:
- [`GUIA_DE_SKILLS.md`](./GUIA_DE_SKILLS.md): Guia prático de especificação e desenvolvimento de novas Skills (instruções de `SKILL.md`, `skills.json`, Action Cards interativos, etc.).
- [`ARQUITETURA_INTEGRACAO.md`](./ARQUITETURA_INTEGRACAO.md): Documento detalhando a arquitetura de integração entre o repositório de Skills e a extensão de navegador (`extensao_geral`).

### 📚 Bases Teóricas e Fontes para o NotebookLM:
- [`META_PROMPTING_E_TAGS_XML.md`](./META_PROMPTING_E_TAGS_XML.md): Conceitos de Meta-Prompting, isolamento de escopo por tags XML (Anthropic) e links de referência.
- [`DIRETRIZES_PROMPTING_GEMINI.md`](./DIRETRIZES_PROMPTING_GEMINI.md): Boas práticas oficiais de System Instructions do Google Gemini, limites de contexto e fontes.
- [`ENGENHARIA_PROMPTS_E_ARQUITETURA_AGENTES.md`](./ENGENHARIA_PROMPTS_E_ARQUITETURA_AGENTES.md): Padrões de arquitetura de agentes modulares, esquemas de Action Cards JSON e links de referência (Fabric, Learn Prompting).
